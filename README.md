# Temporal Rules and Model Explanations for Threat Hunting

Code, mined rules and host-level results for the paper

> N. Kekatos, P. Sinha, A. A. Bruto da Costa, A. Lekidis, P. Mitra, M. Korgiala-Karyda and M. Curcă,
> "Temporal Rules and Model Explanations for Threat Hunting: A Comparative Study,"
> CyberHunt 2026 (IEEE BigData 2026 workshops).

The paper compares six ways of turning labelled traffic into threat-hunting queries: a temporal
rule miner (PSI-Miner), RIPPER, a depth-3 decision tree, gradient boosting with SHAP, Anchors, and
an exhaustive search over two-step rules. Rule outputs are compiled to SQL and scored as hunt
queries on held-out hosts, on a synthetic control and on a MAWI backbone trace with MAWILab labels.

## Data

The MAWI traces and MAWILab labels are public:
- traces: https://mawi.wide.ad.jp/mawi/ (19 November 2024 and 23 June 2024, 14:00);
- labels: https://www.fukuda-lab.org/mawilab/ (v1.1).

Host identifiers in `hosts.csv` and `split.csv` are hashes of the anonymised MAWI addresses.
The per-second host traces are not included because of their size (about 1 GB) and can be
regenerated with `code/mawi_extract.py`. Set `MAWI_DIR` to the folder holding the downloaded trace
and label files.

## PSI-Miner

PSI-Miner is available at https://github.com/antoniobruto/PSIMiner (GPL-3.0). The runs used commit
`b0d03160a5a2aab00a43b31c3deb0e9036eb8ce4` with `code/psiminer_patch/psiminer_fixes.patch` applied.
The patch fixes memory-safety errors and gives identical rules on all runs that the unpatched build
completed. Build it and set `PSIMINER` to the binary:

```sh
git clone https://github.com/antoniobruto/PSIMiner.git && cd PSIMiner
git checkout b0d03160a5a2aab00a43b31c3deb0e9036eb8ce4
git apply /path/to/this/repo/code/psiminer_patch/psiminer_fixes.patch
./build.sh
export PSIMINER=$PWD/build/psiMiner
```

## Running

```sh
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cd code
bash xai_sweep.sh        # synthetic control: stray events and delay sweep, seeds 1-3
bash xai_sweep_b1.sh     # the same with PSI-Miner bias +1
bash run_split_sweep.sh  # MAWI five splits (needs MAWI_DIR and PSIMINER)
```

The synthetic results are deterministic for a given seed and are regenerated by the scripts above;
they are not stored in this repository.
